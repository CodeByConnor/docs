## What is Ramp MCP?

Ramp MCP allows you to securely connect Ramp with AI assistants like ChatGPT and Claude, so you can query Ramp data and take actions with natural language. Admins can analyze data to identify spend trends and forecasting insights, while employees can check balances, request reimbursements, or get policy answers directly from their daily tools.

## Example Use Cases

### Data Analysis

```text title="Data analysis prompts"
"What were our top expenses last month?"
"Show me all transactions over $5,000 from the past 30 days"
"Analyze our software spending by vendor"
"Analyze our recent expenses for any anomalies"
```

### Employee Workflows

```text title="Employee workflow prompts"
"How do I request funds for a team dinner?"
"What is our company policy for getting funds for an offsite?"
"Show me my team's transactions from the past 30 days that are missing receipts or memos, and draft reminder messages I can send to the team to resolve them."
"I'm about to buy these office supplies on Amazon — here's my cart screenshot. Can you verify everything is within policy?"
```

## Getting Started

### Prerequisites

- A Ramp production or sandbox account
- Access to your chosen AI platform (Claude, ChatGPT, etc.)

### Using demo data

Replace `https://mcp.ramp.com/mcp` with `https://demo-mcp.ramp.com/mcp` in any config below to use sample data instead of live Ramp data.

### Claude Code

Add the Ramp MCP server to your Claude Code session:

```bash title="Add Ramp MCP to Claude Code"
claude mcp add --transport http ramp https://mcp.ramp.com/mcp
```

Run `/mcp` in your session to verify the connection.

### Cursor

<Note>
  The Cursor desktop app must be installed for this one-click link to work.
</Note>

Or add manually to `~/.cursor/mcp.json`:

```json title="Cursor MCP Configuration"
{
  "mcpServers": {
    "ramp": {
      "command": "npx",
      "args": ["mcp-remote", "https://mcp.ramp.com/mcp"]
    }
  }
}
```

### Claude Desktop

Add the following to your Claude Desktop config file:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json title="Claude Desktop Configuration"
{
  "mcpServers": {
    "ramp": {
      "command": "npx",
      "args": ["mcp-remote", "https://mcp.ramp.com/mcp"]
    }
  }
}
```

### VS Code (Copilot)

Add the following to your VS Code MCP settings:

```json title="VS Code MCP Configuration"
{
  "servers": {
    "ramp": {
      "type": "http",
      "url": "https://mcp.ramp.com/mcp"
    }
  }
}
```

### Windsurf, Continue, and other MCP clients

For any MCP-compatible client, use the server URL to configure a connection:

- Production: `https://mcp.ramp.com/mcp`
- Demo: `https://demo-mcp.ramp.com/mcp`

Check your tool's MCP documentation for configuration format.

## Verify your connection

After setup, try a prompt to confirm everything is working:

- "What Ramp cards do I have?"
- "Show me my recent transactions"

In Claude Code, run `/mcp` to check that the Ramp server appears in your connected servers list.


## Managing Employee Access

Admins can control which employees have access to Ramp MCP through Integrations:

1. Navigate to `Company -> Integrations -> Ramp MCP` in your Ramp dashboard
2. Select "Manage Access"
3. Set restrictions based on roles, departments, or specific users

This provides fine-grained control over who can use AI copilots to access Ramp data and functionality.

## User Permissions & Access

- **Employee Tools**: Available to all Ramp users, but respect individual user permissions (for example, users will only see funds and cards available to their account)
- **Admin Tools**: Only available to users with admin or business owner permissions

## Troubleshooting

### Connection Issues

Authentication fails or connection drops:

- Claude Code: Run `/mcp`, select Ramp, and choose "Clear authentication"
- Cursor / Claude Desktop: Remove and re-add the server in your config, then restart the app
- ChatGPT: Disconnect and reconnect the Ramp app in `Settings -> Apps`
- Clear cached MCP auth: `rm -rf ~/.mcp-auth` (if applicable)
- Ensure you're logged into the correct Ramp account


"ETL operation limit reached":

- Wait for current data operations to complete
- Ask the AI to clear unused tables to free up resources

"Query returned more than 100 rows":

- The AI will automatically add more specific filters and retry

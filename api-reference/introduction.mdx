The **API reference** tab lists operations generated from Ramp’s OpenAPI document:

`https://docs.ramp.com/openapi/developer-api.json`

## Base URLs

| Environment | API host |
| --- | --- |
| Production | `https://api.ramp.com` |
| Sandbox | `https://demo-api.ramp.com` |

## Authentication

Use OAuth 2.0 access tokens. See [Authorization](/developer-api/v1/developer-resources/authorization) and [Getting started](/developer-api/v1/getting-started/getting-started).

## Plain-text reference

Ramp also publishes a generated plain-text API reference at [llms-api.txt](https://docs.ramp.com/llms-api.txt) for tooling and LLM workflows.

<Tip>
  Use the sidebar under **Endpoints** to browse by tag. If anything is missing compared to the live site, compare with [docs.ramp.com](https://docs.ramp.com/) and the OpenAPI URL above.
</Tip>
